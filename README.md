## Getting Started

### Clone the Repository

```bash
git clone https://github.com/riadhasanmitul/Competitive-Programming.git
```

### Navigate to the Repository

```bash
cd Competitive-Programming
```

### Compile a Solution

```bash
g++ solution.cpp -o solution
```

### Run

```bash
./solution
```
